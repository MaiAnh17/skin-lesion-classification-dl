# HAM10000 Skin Lesion Classification

Deep learning project for multi-class skin lesion classification
using the HAM10000 dataset.


## Team Responsibilities

| Member | Responsibility | Branch |
|---|---|---|
| Member A | Data Understanding, Cleaning, Patient-aware Split | feature/data-pipeline |
| Member B | Preprocessing, Augmentation, Simple CNN | feature/preprocessing |
| Member C | Complex CNN, Transfer Learning | feature/models |
| Member D | Fine-tuning, Evaluation, Error Analysis | feature/evaluation |

## Models

1. Simple CNN
2. Complex CNN
3. Transfer Learning
4. Fine-Tuned Transfer Learning

## Dataset

HAM10000 — Human Against Machine with 10000 training images.
